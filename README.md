# עַגְלִי — חידות "מי אני" בעברית

**משחקים כאן: <https://doronkapah.github.io/MiAni/>**

משחק חידות בעברית, מגיל 4 ועד מבוגרים. בוחרים פרופיל, בוחרים עולם, ומקבלים
חידה עם רמזים שנחשפים אחד־אחד. התשובות נבדקות בסלחנות מלאה לשגיאות כתיב;
החידות עצמן כתובות בעברית תקנית ומנוקדת.

**ארבעה עולמות**, לכל אחד התקדמות משלו:

| עולם | חידות | רמות | האוסף | הקבוצות |
| --- | --- | --- | --- | --- |
| 🛒 הסופר | 101 | 1–4 | העגלה שלי | מתכונים |
| 🪐 החלל | 45 | 1–6 | יומן החלל | מסעות |
| 🏅 אולימפיאדה | 44 | 2–6 | ארון המדליות | נבחרות |
| 🏰 דיסני | 40 | 1–6 | אלבום הקסם | סיפורים |

> המספרים כאן הם לתחזוקה. **בתוך המשחק לא מוצג גודל הבנק** — מספר סופי
> הופך את המשחק למשימה שנגמרת, ומזמין מרוץ במקום סקרנות. השחקן רואה את
> הרמה שהגיע אליה וכמה פתר, לא מתוך כמה.

- **הכול על המכשיר.** פרופילים, התקדמות, עגלה ומוני שימוש חיים ב-`localStorage`
  של הדפדפן. אין מסד נתונים, אין חשבונות, ואין שרת שרואה משהו.
- **מתארח כאתר סטטי** ב-GitHub Pages. אין פונקציות ואין סודות בענן.
- **עובד אופליין.** אחרי ביקור אחד המשחק זמין גם בלי רשת, וניתן להתקנה כאפליקציה.
- **230 חידות** ב-6 רמות קושי שמתאימות את עצמן לשחקן, בנפרד בכל עולם.
- **ניקוד.** 603 מהרמזים — כל אלה שברמות 1–4 — כתובים גם מנוקדים, דלוק
  כברירת מחדל לגילאי 4–7. ברמות 5–6 הקהל כבר קורא בלי ניקוד.
- **מדף שמרמז.** השלט והפריטים שעליו מראים איפה החידה יושבת — מעבר בסופר,
  אזור ביקום או ענף ספורט — ומרמזים פחות ככל שהרמה עולה.
- **18 קבוצות** שנפתחות לבד כשמצטברים כל הפריטים שלהן: מתכונים בסופר,
  מסעות בחלל, נבחרות באולימפיאדה וסיפורים בדיסני.
- **חידת היום** — חידה אחת ליום, זהה לכל מי שנמצא באותה רמה, שמזכה בכוכבים.
- **מצב "הורה שואל"** לנסיעה: ההורה מקריא, הילדים עונים בפה.
- **עידוד** — רצף תשובות נכונות, ו"מדהים!" למי שפתר בלי רמזים.
- **25 דמויות** לבחירה בפרופיל, בשתי קבוצות: "המומלצים של ארבל!" (חד קרן, ארנב,
  חתול, כלב, דוב, פינגווין, דרקון, צפרדע) ופריטי הסופר.

## איך זה בנוי

```
הדפדפן של המשתמש                            הענן
──────────────────────────                  ──────────────────
localStorage                                CDN סטטי
  פרופילים, התקדמות, עגלה                     index.html + JS + CSS
  קבוצות, מוני שימוש, יומן                    230 חידות בתוך החבילה
       │
       └─────────────── HTTPS ─────────────→ api.anthropic.com
                (רק אם מפעילים את עגלי)
```

כל לוגיקת המשחק — התאמת התשובות, הדירוג, בחירת החידה, מסנן התשובה — יושבת
ב-`shared/` ורצה בדפדפן. השרת ב-`server/` הוא **אופציונלי** ועושה רק שני דברים:
מגיש את האתר הבנוי, ומחזיק מפתח API כדי שלא צריך להדביק אותו בדפדפן.

## פרסום

```bash
npm run build          # יוצר dist-web/
npm run preview        # בדיקה מקומית של הבנייה
```

**GitHub Pages מוגדר ועובד.** כל דחיפה ל-`main` מריצה את
`.github/workflows/deploy.yml`, שמריץ בדיקות ובדיקת טיפוסים, בונה, ומפרסם.
הבנייה מקבלת `BASE_PATH=/<repo>/` כי Pages מגיש תחת תת-נתיב, ומעתיקה את
`index.html` גם ל-`404.html` כ-SPA fallback.

**אירוח אחר:** מעלים את `dist-web` לכל CDN סטטי. צריך HTTPS (ל-service worker
ולהתקנה) ו-SPA fallback. אם האתר בשורש הדומיין, אין צורך ב-`BASE_PATH`.

לאינדוקס במנועי חיפוש ובמנועי AI — ראו **[docs/seo.md](seo.md)**.

## שני מצבי משחק

**ילד משחק** — ברירת המחדל. הילד בוחר פרופיל, קורא את הרמזים ומקליד תשובות.

**הורה שואל** — לרגעים בלי מקלדת: נסיעה, ארוחה, תור לרופא. ההורה בוחר אילו
ילדים משתתפים ובאיזו רמה (ברירת המחדל: הרמה של הצעיר), מקריא את הרמזים בקול,
ומקיש מי פתר. ההורה רואה את התשובה בפס נפרד.

| ניקוד | מה קורה |
|---|---|
| **תחרותי** | רק מי שפתר ראשון מקבל את הפריט לעגלה שלו |
| **שיתוף פעולה** | מספיק שאחד אמר — כולם מקבלים |

החידה נבחרת מבין אלה שאף משתתף עוד לא פתר. הצ׳אט כבוי במצב הזה — ההורה הוא
העוזר.

## מתכונים

מתכון נפתח לבד ברגע שכל המצרכים שלו בעגלה, וקופץ על המסך. נשמר בפרופיל,
ואפשר לחזור אליו דרך ספר המתכונים.

| מתכון | מצרכים |
|---|---|
| חביתה | ביצה, חמאה, מלח |
| סלט פירות | ארבעה פירות כלשהם מתוך שבעה |
| כדורי שוקולד | ביסקוויטים, שוקולד, חמאה, חלב |
| פנקייקים | קמח, ביצה, חלב, סוכר, אבקת אפייה |

מתכון נעול מציג רק **כמה** מצרכים חסרים, אף פעם לא אילו — שם של מצרך שעוד לא
נפתר הוא תשובה לחידה. יש בדיקה שמוודאת שזה נשאר נכון.

- **דילוג** — התשובה לא מוצגת, ולכן גם אין ירידה בדירוג. החידה חוזרת לתור.
- **השתקה** — כפתור 🔊/🔇 בסרגל, נשמר לכל שחקן.

## נתוני שימוש

**לוח הורים ← 📊 סיכום שימוש.** מונים מצטברים שנשמרים על המכשיר: כמה חידות
נפתרו, דיוק לכל ילד, רמזים בממוצע, פעילות יומית בשבועיים האחרונים, ואילו חידות
הכי הקשו.

נשמרים **מונים בלבד** — מה שהילד הקליד לא נשמר שם. אין שירות מדידה חיצוני, אין
cookies ואין שליחה לשום שרת. המונים נכללים בקובץ הגיבוי.

### שליחת סיכום אנונימי

בתחתית מסך הסיכום יש כפתור שבונה דוח אנונימי — מספרים ושמות חידות בלבד, בלי
שמות שחקנים, גילאים, מזהים או טקסט שהוקלד. **שום דבר לא נשלח אוטומטית:** הדוח
מוצג במלואו על המסך, ורק אז אפשר לשלוח אותו בוואטסאפ או להעתיק.

> **למה לא Google Analytics?** cookie הוא אחסון בדפדפן של המבקר, בדיוק כמו
> `localStorage`. הוא מגיע אליכם רק אם יש שרת שמקבל אותו — ולמשחק הזה אין. כל
> אנליטיקה אמיתית מחייבת שירות צד שלישי, שינוי בתנאי השימוש, והתמודדות עם
> רגולציה על איסוף מידע מילדים.

## יומן המשחק

**לוח הורים ← יומן המשחק.** 300 האירועים האחרונים — חידה חדשה, ניחוש ותוצאתו,
רמז, דילוג, "גלה לי", מתכון שנפתח, ומי פתר במצב הורה. אפשר להוריד כ-JSON או
לנקות. אותן שורות מודפסות גם לקונסולת הדפדפן (F12) עם התחילית `[עגלי·scope]`.

## עגלי — עוזר הסופר

> **התכונה מוסתרת כרגע.** המשחק עומד מצוין בלעדיה, והיא החלק היחיד שדורש מפתח
> API וכסף. הקוד נשאר במקומו ועובד — להחזרה, משנים `agaliChat` ל-`true` בקובץ
> `web/src/config.ts` ובונים מחדש.

עוזר שיחה שעונה על שאלות כן/לא על הפריט הסודי, ולעולם לא מגלה אותו. שני מסלולים:

| מסלול | איפה המפתח |
|---|---|
| **מפתח משלי** | ב-`localStorage`; נשלח רק ל-`api.anthropic.com` |
| **המפתח שבשרת** | ב-`.env` על המחשב; הדפדפן לא רואה אותו |

מודלים: `claude-opus-5` (ברירת מחדל, ~$0.009 לתור), `claude-sonnet-5` (~40%
מהעלות), `claude-haiku-4-5` (~20%).

**מפתח API בדפדפן:** נשלח אך ורק אל `api.anthropic.com`, ולא נכלל בגיבוי. מי
שיש לו גישה לדפדפן יכול לחלץ אותו — אין להשתמש במפתח הראשי. מומלץ מפתח ייעודי
ב-workspace נפרד עם תקרת הוצאה חודשית.

## גיבוי והעברה בין מכשירים

"הכול על המכשיר" אומר שהפרופילים לא עוברים לטלפון של אמא מעצמם. לוח ההורים

מה שהבדיקות מכסות: נרמול עברי ומרחק עריכה, כלל ההבחנה, שלמות בנק החידות

התשובה של חידה שיושבת בו. בדיקת השיתוף תופסת את זה.



## הוגנות המשוב

לרמז "אני עגול ואדום, וגדלתי על עץ" התשובה **דובדבן** נכונה לגמרי —
היא פשוט לא החידה הזאת. משחק שעונה על זה "לא הפעם" מלמד ילד
שהחשיבה שלו לא נחשבת.

`shared/plausible.ts` מזהה ניחוש הגיוני בשתי דרכים:

1. **הוא תשובה של חידה אחרת בבנק.** אז הוא בוודאי דבר אמיתי, ואם
   הוא מאותו מקום גם ברור למה הוא עלה בדעת — "גם הוא בפירות וירקות".
2. **הוא ברשימת `alsoFits` של החידה** — חלופות צפויות שנכתבות ביד,
   בלי AI. הן קיימות לכל 87 החידות שברמות 1–2.

**חלופה יכולה להיפסל באמצע החידה.** "קרטיב" מתאים ל"אני קר מאוד
וגר במקפיא", ונפסל ברגע שנחשף "אוכלים אותי בגביע":

```json
{ "guess": "קרטיב", "ruledOutBy": 2,
  "because": "קרטיב אוכלים ממקל או משקית, ואני בגביע." }
```

לפני הרמז המשחק אומר "ניחוש חכם, והוא באמת מתאים לרמזים". אחריו —
"התאים יפה קודם! אבל לפי הרמז החדש…" וההבדל. להמשיך לומר שהניחוש
מתאים אחרי שרמז פסל אותו זה שקר קטן שילד יכול לתפוס.

בשני המקרים המשחק מודה שהניחוש הגיוני, ומציע כפתור **"רמז שיבדיל
ביניהם"**. הכללים ב-`scripts/riddle-rules.ts` פוסלים חלופה שהמנוע
מקבל בכל זאת כתשובה נכונה — אחרת היא לא חלופה, הילד פשוט צדק.

## יכולת, ולא רק גיל

גיל הוא ניחוש גס לשלושה דברים שונים. המשחק שואל את שלושתם בנפרד:

| מה | איפה נשמר | מה זה משנה |
|---|---|---|
| ידע | `worlds[world].rating` | קושי החידות, בנפרד בכל עולם |
| קריאה | `profile.reading` | ניקוד והקראה |
| הקלדה | `profile.answering` | הקלדה מול בחירה מתוך ארבע תמונות |

פרופילים שנוצרו לפני השדות האלה נגזרים מהגיל, ולא משתנים.
`shared/choices.ts` מייצר את ארבע האפשרויות, לפי שני כללים בסדר הזה:

1. **ארבע צורות שונות.** ילד שלא קורא רואה ציורים, ואם שלוש
   מהאפשרויות הן אותו כיכר לחם בגוונים שונים — אין כאן בחירה.
2. אחרי זה, מסיחים קרובים ככל האפשר: אותו מדף, אחר כך אותו עולם.

הסדר יציב ולא קופץ בין רינדורים. הרשימה נשלחת רק למי שעונה בבחירה —
היא מכילה את התשובה מעצם הגדרתה.

לכל אפשרות יש כפתור שמיעה **נפרד מהבחירה**: צריך אפשרות לשמוע מה
כתוב בלי להגיש את זה כתשובה. וכשאין קול עברי במכשיר, המשחק אומר
את זה במקום לשתוק — במצב שכולו נשען על הקראה, שתיקה שקטה משאירה
ילד בלי כלום.


## מצב ההורה והמשחק העצמאי

**זו אותה התקדמות, לא שתיים.** סבב "הורה שואל" כותב לאותו
`worlds[world].rating`, החידה נכנסת ל-`solved` ולא תחזור במשחק
העצמאי, והפריט נכנס לאותו אוסף.

זו ההתנהגות הנכונה — לילד יש התקדמות אחת — אבל היא הייתה בלתי
נראית, וההורה גילה אותה רק כשהחידות במשחק העצמאי נעשו קשות. עכשיו
זה כתוב במסך ההכנה ובסיכום הסבב, ויש בדיקות שמתעדות את זה במפורש
כדי שאם מישהו ישנה את ההתנהגות הוא יראה שזו החלטה.

בשיתוף פעולה גם מי שלא ענה מתקדם. גם זו כוונה, ולא תופעת לוואי.

## יעדים

`nextGoal` בוחר את הסט הקרוב ביותר להשלמה, ובשוויון — את זה שאפשר
להגיע אליו מהרמות הנמוכות ביותר. הפס מעל החידה מראה את השם, את מה
שכבר נאסף, ומשבצות ריקות לְמה שחסר. **מה שחסר לא מוצג בשמו**: שם של
פריט חסר הוא התשובה של חידה שעוד לא נשאלה.

## עברית

`shared/hebrew.ts` מטפל ביחיד, זוגי ורבים ובהתאמת מין — "פריט אחד",
"שתי חידות", "נפתחה נבחרת חדשה". בעברית אין s בסוף, ויש צורת זוגי,
ולכן זה לא נגזר ממספר לבד.

## חידת היום

חידה אחת ליום, שנבחרת מהתאריך ומהרמה של השחקן — בלי שרת ובלי הגרלה
שנשמרת. שני ילדים באותה רמה מקבלים את אותה חידה, וזה מה שהופך אותה
למשהו שאפשר לדבר עליו.

הפרס הוא **כוכבים** ולא דירוג: שלושה למי שפתר בלי רמז נוסף, שניים
אחרי רמז, אחד אחרי שניים. הפתרון נכנס לאוסף של העולם שממנו החידה
באה, אבל לא מזיז את הדירוג — חידת היום היא טקס, לא שיעור.

**רצף ימים** נשבר בוויתור ומתאפס ביום שדולג. אין הצלת רצף, ואין
תזכורות. מי שלא נכנס יום אחד פשוט מתחיל מחדש.

## סוכן כתיבת החידות

```bash
npm run riddles:write                  # העולם והרמה הדלים ביותר בבנק
npm run riddles:write -- disney 3      # עולם ורמה מפורשים
npm run riddles:write -- --count 8

npm run riddles:promote                # בדיקה: מה מאושר ומה ייכנס
npm run riddles:promote -- --write     # מחיל על הבנק
```

הסוכן מבקש חידות מ-Claude, מריץ על כל אחת את `scripts/riddle-rules.ts`,
וכותב את מה שעבר ל-`shared/data/drafts.json`. **הוא לא נוגע בבנק.**
חידה נכנסת למשחק רק אחרי ש-`approved: true` סומן ידנית והורץ
`riddles:promote -- --write`. אין דגל שעוקף את זה.

הכללים שהוא אוכף — כל אחד מהם נולד מבאג אמיתי:

| כלל | מה זה מונע |
|---|---|
| הרמז לא מכיל את התשובה | "בים המלח" בחידה על מלח |
| שם המקום לא מכיל את התשובה | "טלסקופ" ב"טלסקופים ותחנות", והשלט נשלח בשיתוף |
| התשובה רחוקה מכל תשובה בבנק | "אתונה" התקבלה כ"טונה" |
| כתיב מלא בטקסט המנוקד | הגרסה בלי ניקוד יצאה "אזנים" ו"כלם" |
| המנוקד תואם לרגיל אות באות | שתי הגרסאות נפרדות זו מזו |
| המקום והרמה קיימים בעולם | חידה שנוחתת על שלט שלא קיים |

`.github/workflows/daily-riddles.yml` מריץ את זה כל בוקר ופותח PR.
הוא דורש `ANTHROPIC_API_KEY` ב-Secrets של המאגר; בלעדיו הוא מדלג
בשקט. הוא לא דוחף ל-main.

## הוספת חידות

עורכים את `shared/data/riddles.json` ומריצים `npm test` ו-`npm run report:collisions`.
הבדיקות יתריעו אם רמז מכיל את התשובה, אם שתי חידות חולקות תשובה, אם צבע לא
תקין, או אם תשובה חדשה קרובה מדי לתשובה קיימת.

```json
{
  "id": "pasta",
  "world": "market",
  "level": 2,
  "aisle": "יבשים",
  "answer": "פסטה",
  "answerNikud": "פַּסְטָה",
  "aliases": ["ספגטי", "מקרוני", "אטריות"],
  "clues": ["רמז ראשון", "רמז שני", "רמז שלישי"],
  "cluesNikud": ["רֶמֶז רִאשׁוֹן", "רֶמֶז שֵׁנִי", "רֶמֶז שְׁלִישִׁי"],
  "reveal": "משפט הסבר שמוצג אחרי הפתרון",
  "art": { "shape": "packet", "color": "#E8C87A" }
}
```

הרמזים המנוקדים לא נערכים ב-`riddles.json` ישירות. מקור האמת הוא
`shared/data/clues-nikud.json`, וממנו נגזרים גם הרמזים ללא ניקוד:

```bash
npm run merge:nikud              # בדיקה בלבד — מדפיס כל שינוי נוסח
npm run merge:nikud -- --write   # מחיל על riddles.json
```

הרמות: 1 = שני רמזים והקראה אוטומטית, 2 = שלושה רמזים, 3–6 = ארבעה רמזים.
`world` חייב להיות אחד מאלה שב-`shared/worlds.ts`, ו-`aisle` חייב להיות מקום
שקיים באותו עולם ב-`shared/aisles.ts`. `cluesNikud` נדרש ברמות 1–4 בלבד.
הצורות ב-`art.shape` מוגדרות ב-`web/src/art/Product.tsx`.

**אחרי הוספת חידות** — עדכנו את המספרים גם ב-`web/index.html`,
ב-`web/public/llms.txt` וכאן. הרשימה המלאה בנספח של [docs/seo.md](seo.md).

## הגנה על התשובה

1. **הוראה חדה בפרומפט** של עגלי: אסור לומר, לאיית, לרמוז על אותיות או לתרגם.
2. **מסנן פלט** עם חוצץ של 24 תווים, שתופס את התשובה גם כשהיא מתפצלת בין שני
   קטעי סטרימינג וגם כשהיא נכתבת מרווחת.
3. **הציור של המוצר** מוסתר עד הפתרון — הצורה לבדה מסגירה חצי חידה.
4. **הודעת השיתוף** נבדקת מול כל 230 החידות שהיא לא מכילה את התשובה.

**מה שאין:** מאז שהמשחק רץ כאתר סטטי, בנק החידות נמצא בחבילת ה-JavaScript.
ילד עם DevTools יכול למצוא שם את התשובה. זה המחיר של "כל הנתונים על המכשיר",
ואי אפשר לקבל את שניהם. האיום המעשי — שעגלי יסגיר את התשובה בשיחה — עדיין חסום.
