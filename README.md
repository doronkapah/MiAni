# עַגְלִי — חידות "מי אני" בסופר

**משחקים כאן: <https://doronkapah.github.io/MiAni/>**

משחק חידות בעברית לילדים בגילאי 4–10. כל ילד בוחר פרופיל, מקבל חידה עם רמזים
שנחשפים אחד־אחד, ויכול לשאול את עַגְלִי — עגלת קניות מדברת — שאלות כן/לא.
התשובות של הילדים נבדקות בסלחנות מלאה לשגיאות כתיב; החידות עצמן כתובות
בעברית תקנית ומנוקדת.

- **הכול על המכשיר.** פרופילים, התקדמות, עגלה, מפתח ה-API ומוני השימוש חיים
  ב-`localStorage` של הדפדפן. אין מסד נתונים, אין חשבונות, ואין שרת שרואה משהו.
- **מתארח כאתר סטטי.** מעלים את `dist-web` לכל CDN. אין פונקציות ואין סודות בענן.
- **עובד אופליין.** אחרי ביקור אחד המשחק זמין גם בלי רשת, וניתן להתקנה כאפליקציה.
- **ניקוד.** כל 260 הרמזים כתובים גם מנוקדים, דלוק כברירת מחדל לגילאי 4–7.
- **25 דמויות** לבחירה בפרופיל, בשתי קבוצות: "המומלצים של ארבל!" (חד קרן, ארנב,
  חתול, כלב, דוב, פינגווין, דרקון, צפרדע) ופריטי הסופר.
- **מתכונים.** כשמצטברים בעגלה כל המצרכים של מנה, המתכון קופץ על המסך:
  חביתה, סלט פירות, כדורי שוקולד ופנקייקים. יש גם ספר מתכונים.
- **מדף שמרמז.** השלט והמוצרים על המדף מראים באיזה מעבר הפריט נמצא —
  ופחות ופחות ככל שהרמה עולה.
- **מצב "הורה שואל"** לנסיעה: ההורה מקריא, הילדים עונים בפה, תחרותי או
  בשיתוף פעולה.
- **עידוד** — רצף תשובות נכונות עם אבני דרך, ו"מדהים!" למי שפתר בלי רמזים.
- **שיתוף חידה** לוואטסאפ כדי לבקש עזרה מחברים — בלי התשובה.
- **דילוג והשתקה** — כפתור דילוג על חידה, וכפתור להשתקת ההקראה.
- **בחירת מודל** — Opus 5, Sonnet 5 או Haiku 4.5, מלוח ההורים.

## איך זה בנוי

```
הדפדפן של המשתמש                            הענן
──────────────────────────                  ──────────────────
localStorage                                CDN סטטי
  פרופילים, התקדמות, עגלה                     index.html + JS + CSS
  מפתח API, בחירת מודל                        80 חידות בתוך החבילה
  מוני שימוש ועלות
       │
       └─────────────── HTTPS ─────────────→ api.anthropic.com
                (רק כשמדברים עם עגלי)
```

כל לוגיקת המשחק — התאמת התשובות, הדירוג, בחירת החידה, מסנן התשובה — יושבת
ב-`shared/` ורצה בדפדפן. השרת ב-`server/` הוא **אופציונלי** ועושה רק שני דברים:
מגיש את האתר הבנוי, ומחזיק מפתח API כדי שלא צריך להדביק אותו בדפדפן.


### GitHub Pages — מוגדר ועובד

כל דחיפה ל-`main` מריצה את `.github/workflows/deploy.yml`, שמריץ בדיקות, בונה
ומפרסם. הבנייה מקבלת `BASE_PATH=/<repo>/` כי Pages מגיש תחת תת-נתיב, ומעתיקה
את `index.html` גם ל-`404.html` כ-SPA fallback.

### אירוח אחר

מעלים את `dist-web` לכל אירוח סטטי — Cloudflare Pages, Netlify, Vercel. כולם
חינם לזה. **צריך HTTPS** כדי שה-service worker וההתקנה יעבדו, ו-**SPA fallback**
כדי שכל נתיב יחזיר את `index.html`. אם האתר יושב בשורש הדומיין, אין צורך
ב-`BASE_PATH`.

אין משתני סביבה, אין סודות, ואין מה להגדיר בצד השרת.

## נתוני שימוש

**לוח הורים ← סיכום שימוש.** מונים מצטברים שנשמרים על המכשיר: כמה חידות נפתרו,
דיוק הניחושים לכל ילד, כמה רמזים בממוצע לחידה, פעילות יומית בשבועיים האחרונים,
ואילו חידות הכי הקשו.

אין כאן שירות מדידה חיצוני, אין cookies ואין שליחה לשום שרת — הכול נספר מקומית.
המונים נכללים בקובץ הגיבוי, כדי שיעברו איתכם למכשיר אחר.

### שליחת סיכום אנונימי

בתחתית מסך הסיכום יש כפתור שבונה דוח אנונימי — מספרים ושמות חידות בלבד, בלי
שמות שחקנים, גילאים, מזהים או טקסט שהוקלד. **שום דבר לא נשלח אוטומטית:** הדוח
מוצג במלואו על המסך, ורק אז אפשר לשלוח אותו בוואטסאפ או להעתיק.

> **למה לא Google Analytics?** cookie הוא אחסון בדפדפן של המבקר, בדיוק כמו
> `localStorage`. הוא מגיע אליכם רק אם יש שרת שמקבל אותו — ולמשחק הזה אין. כל
> אנליטיקה אמיתית מחייבת שירות צד שלישי, שינוי בתנאי השימוש, והתמודדות עם
> רגולציה על איסוף מידע מילדים.

## יומן המשחק

המשחק רץ כולו בדפדפן, ולכן אין שרת עם לוגים. במקום זה נשמר יומן מקומי של
300 האירועים האחרונים — חידה חדשה, ניחוש ותוצאתו, רמז, "גלה לי", מתכון שנפתח,
ומי פתר במצב הורה. רואים אותו ב**לוח ההורים ← יומן המשחק**, ואפשר להוריד אותו
כקובץ JSON או לנקות אותו.

אותן שורות מודפסות גם לקונסולת הדפדפן (F12 ← Console), עם התחילית `[עגלי·scope]`.
היומן נשאר על המכשיר ולא נשלח לשום מקום.

## עגלי — עוזר הסופר

> **התכונה מוסתרת כרגע.** המשחק עומד מצוין בלעדיה, והיא החלק היחיד שדורש מפתח
> API וכסף. הקוד נשאר במקומו ועובד — להחזרה, משנים `agaliChat` ל-`true` בקובץ
> `web/src/config.ts` ובונים מחדש.

הצ׳אט הוא החלק היחיד שדורש אינטרנט וכסף. **כל שאר המשחק עובד בלעדיו**:
חידות, רמזים, בדיקת תשובות, פרופילים, רמות והקראה קולית.

יש שני מסלולים, ובוחרים ביניהם בלוח ההורים:

| מסלול | מתי | איפה המפתח |
|---|---|---|
| **מפתח משלי** | אירוח סטטי, או כל מכשיר | ב-`localStorage` של הדפדפן; נשלח רק ל-`api.anthropic.com` |
| **המפתח שבשרת** | כשמריצים את השרת המקומי | ב-`.env` על המחשב; הדפדפן לא רואה אותו |

### מפתח API בדפדפן — מה חשוב לדעת

- המפתח נשמר במכשיר ונשלח **אך ורק** אל `api.anthropic.com`. הוא לא עובר בשום
  שרת שלנו, ולא נכלל בקובץ הגיבוי.
- מי שיש לו גישה לדפדפן יכול לחלץ אותו. **אין להשתמש במפתח הראשי של החשבון.**
- מומלץ ליצור ב-Anthropic Console מפתח ייעודי ב-workspace נפרד, עם **תקרת הוצאה
  חודשית**. זו ההגנה האמיתית מפני הפתעות.

לדולרים היא הערכה. החיוב האמיתי נמצא ב-Anthropic Console.

### לוח ההורים

נכנסים אליו מהקישור בתחתית מסך בחירת השחקנים, אחרי תרגיל כפל קטן (לא אבטחה —
רק מספיק כדי שילד בן שש לא ישנה הגדרות בטעות). יש בו מפתח API, בחירת מודל, מעקב
עלות, תקרה יומית, וגיבוי.

## גיבוי והעברה בין מכשירים

"הכול על המכשיר" אומר שהפרופילים לא עוברים לטלפון של אמא מעצמם. לוח ההורים
מוריד קובץ JSON ומעלה אותו במכשיר אחר. הקובץ לא כולל את מפתח ה-API, וייבוא
חוזר לא משכפל שחקנים קיימים.

## הוספת חידות

עורכים את `shared/data/riddles.json` ומריצים `npm test` ו-`npm run report:collisions`.
הבדיקות יתריעו אם רמז מכיל את התשובה, אם שתי חידות חולקות תשובה, או אם תשובה
חדשה קרובה מדי לתשובה קיימת.

```json
{
  "id": "pasta",
  "level": 2,
  "aisle": "יבשים",
  "answer": "פסטה",
  "answerNikud": "פַּסְטָה",
  "aliases": ["ספגטי", "מקרוני", "אטריות"],
  "clues": ["רמז ראשון", "רמז שני", "רמז שלישי"],
  "cluesNikud": ["רֶמֶז רִאשׁוֹן", "רֶמֶז שֵׁנִי", "רֶמֶז שְׁלִישִׁי"],
  "reveal": "משפט הסבר שמוצג אחרי הפתרון",
  "art": { "shape": "packet", "color": "#E8C87A" }
}
```

הרמזים המנוקדים לא נערכים ב-`riddles.json` ישירות. מקור האמת הוא
`shared/data/clues-nikud.json`, וממנו נגזרים גם הרמזים ללא ניקוד:

```bash
npm run merge:nikud              # בדיקה בלבד — מדפיס כל שינוי נוסח
npm run merge:nikud -- --write   # מחיל על riddles.json
```

## שני מצבי משחק

**ילד משחק** — ברירת המחדל. הילד בוחר פרופיל, קורא את הרמזים ומקליד תשובות.

**הורה שואל** — לרגעים בלי מקלדת: נסיעה, ארוחה, תור לרופא. ההורה בוחר אילו
ילדים משתתפים ובאיזו רמה (ברירת המחדל: הרמה של הצעיר, כדי שכולם יוכלו),
מקריא את הרמזים בקול, ומקיש מי פתר. ההורה רואה את התשובה בפס נפרד — הוא
מנהל את המשחק.

| ניקוד | מה קורה |
|---|---|
| **תחרותי** | רק מי שפתר ראשון מקבל את הפריט לעגלה שלו |
| **שיתוף פעולה** | מספיק שאחד אמר — כולם מקבלים. בלי מפסידים |

החידה נבחרת מבין אלה שאף אחד מהמשתתפים עוד לא פתר. הצ׳אט עם עגלי כבוי
במצב הזה — ההורה הוא העוזר.

## המדף כרמז

השלט על המדף והמוצרים שעליו מספרים באיזה מעבר הפריט נמצא, והרמז נחלש
ככל שהרמה עולה:

| רמה | השלט | המוצרים |
|---|---|---|
| 1–2 | המעבר המדויק — "פירות וירקות" | תואמים למעבר |
| 3 | האזור הכללי בלבד — "מזון טרי" | ניטרליים |
| 4 | "מדף מסתורי" | ניטרליים |

בדיקה אוטומטית מוודאת שכל אזור מכסה יותר ממעבר אחד — אחרת הוא לא מחליש כלום.

## מתכונים

מתכון נפתח לבד ברגע שכל המצרכים שלו בעגלה, וקופץ על המסך. הוא נשמר בפרופיל,
ואפשר לחזור אליו דרך ספר המתכונים בסרגל העליון.

| מתכון | מצרכים |
|---|---|
| חביתה | ביצה, חמאה, מלח |
| סלט פירות | ארבעה פירות כלשהם מתוך שבעה |
| כדורי שוקולד | ביסקוויטים, שוקולד, חמאה, חלב |
| פנקייקים | קמח, ביצה, חלב, סוכר, אבקת אפייה |

מתכון נעול מציג רק **כמה** מצרכים חסרים, אף פעם לא אילו — שם של מצרך שעוד לא
נפתר הוא תשובה לחידה. יש בדיקה אוטומטית שמוודאת שזה נשאר נכון.

הטקסט של המתכונים נשמר מנוקד בלבד, והגרסה בלי ניקוד נגזרת ממנו בזמן ריצה —
כך אין שתי גרסאות שיכולות להתפצל.

## הגנה על התשובה

1. **הוראה חדה בפרומפט** של עגלי: אסור לומר, לאיית, לרמוז על אותיות או לתרגם.
2. **מסנן פלט** עם חוצץ של 24 תווים, שתופס את התשובה גם כשהיא מתפצלת בין שני
   קטעי סטרימינג וגם כשהיא נכתבת מרווחת. רץ בדפדפן בשני מסלולי הצ'אט.
3. **הציור של המוצר** מוסתר עד הפתרון — הצורה לבדה מסגירה חצי חידה.

**מה שאין:** מאז שהמשחק רץ כאתר סטטי, בנק החידות נמצא בחבילת ה-JavaScript.
ילד עם DevTools יכול למצוא שם את התשובה. זה המחיר של "כל הנתונים על המכשיר",
ואי אפשר לקבל את שניהם. האיום המעשי — שעגלי יסגיר את התשובה בשיחה — עדיין חסום.
